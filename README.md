# Customer-Segmentation-project

## Project Overview
This project analyzes customer purchasing behavior and segments customers based on their spending patterns.

## Dataset
Online Retail Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Customer Segmentation using K-Means
5. Customer Retention Analysis
